# 簡單電池 1.0.0-prerelease.1

這是使用 Debug 金鑰簽署的 Pre-release 測試版本，不是正式發行版本，請勿用於正式上架或生產環境。

## 測試內容

- 手機電量、充電狀態與詳細資料。
- 充電電流、估算功率與預估充滿時間。
- 系統、淺色與深色主題及自訂色彩。
- 手機電量、電池溫度與藍牙裝置電量桌面小工具。
- 無外框、圓形進度及直式電池外框。
- 小工具背景、字級、百分比符號及藍牙名稱設定。
- 小工具自由調整尺寸。

## 已知限制

- 部分手機不提供充電電流或預估時間。
- Android 沒有支援所有耳機的公開電量 API；部分耳機可能顯示「等待電量」或「不支援」。
- 背景更新可能受 Android 省電政策延後。
- Debug 簽章與未來正式版本簽章不同，正式版可能需要先移除此測試版。
