# 簡單電池 1.0.0-prerelease.3

這是使用 Debug 金鑰簽署的 Pre-release 測試版本，不是正式發行版本，請勿用於正式上架或生產環境。

## 本次更新

- APP 主題色新增暖陽黃、珊瑚紅、活力橘、青草綠、天空藍及葡萄紫六種預設選項。
- 自訂色彩滑桿的控制點及預覽圓形會即時跟隨手勢，放開後才保存並套用全 APP。
- APP 背景與 Surface 會依目前主題色套用淡色調，並支援淺色與深色模式。
- 顯示模式改為單列排版，避免「跟隨系統」選項換行。
- 主畫面設定按鈕移除圓形背景，右側新增將 APP 切換到背景的按鈕。
- 設定頁返回按鈕改為向左箭頭。
- 設定頁底部新增版本名稱及 Build 資訊。
- 移除色相數值與「恢復預設色彩」按鈕。

## 已知限制

- 小工具主題色仍與 APP 主題色分開設定。
- 各品牌 Android 裝置的電池設定頁面與名稱可能不同。
- 部分手機不提供充電電流或預估時間。
- Android 沒有支援所有耳機的公開電量 API；部分耳機可能顯示「等待電量」或「不支援」。
- 背景更新可能受 Android 省電政策延後。
- Debug 簽章與未來正式版本簽章不同，正式版可能需要先移除此測試版。
