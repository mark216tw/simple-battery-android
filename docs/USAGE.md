# 使用指南

## 主畫面

開啟 APP 後會立即讀取目前電池狀態，顯示：

- 電池百分比。
- 充電中、已充滿或使用電池中的狀態。
- 電源類型、健康狀態、溫度與電壓。
- 充電時的即時電流、估算功率與預估充滿時間。

部分裝置不提供電流或充滿時間，此時會顯示「裝置不支援」。

## APP 外觀

點擊主畫面右上角的齒輪圖示進入設定：

1. 選擇跟隨系統、淺色或深色模式。
2. 拖曳彩色色相滑桿調整 APP 主題色。
3. 所有調整會立即套用。
4. 點擊畫面上的「返回」或手機系統返回鍵回到主畫面。

## 新增桌面小工具

1. 長按 Android 桌面空白位置。
2. 開啟小工具清單。
3. 尋找「簡單電池」。
4. 選擇手機電量、電池溫度或藍牙裝置電量。
5. 將小工具拖曳到桌面。
6. 完成個別設定後按「完成」。

小工具初始尺寸為 1×1，可依 Launcher 支援方式調整寬度與高度。點擊桌面上的小工具可再次編輯該小工具。

## 小工具外觀

每個小工具可獨立設定：

- 主題色。
- 字級大小。
- 無外框、圓形外框或直式電池外框。
- 主題色背景或透明背景。
- 手機及藍牙電量是否顯示 `%`。
- 藍牙小工具是否顯示裝置名稱。

圓形外框會依電量顯示進度；直式電池會由下往上填滿。電池溫度以 0–50°C 換算進度，40°C 以上使用警示色。

## 藍牙裝置電量

1. 新增「藍牙裝置電量」小工具。
2. Android 12 以上請允許「附近裝置」權限。
3. 從已配對裝置中選擇目標裝置。
4. 完成設定。

狀態說明：

- `離線`：選擇的裝置目前沒有連線。
- `等待電量`：裝置已連線，但 APP 尚未收到可用數值；可將耳機斷線後重新連線。
- `不支援`：裝置沒有提供可讀取的電量服務。
- `需要權限`：附近裝置權限未授權。
- `未設定`：尚未選擇裝置。

Android 公開 API 沒有適用所有耳機的統一電量介面。APP 優先使用系統電量事件，並以標準 BLE Battery Service 作為補充，但無法保證支援所有品牌或型號。

## 更新頻率

- APP 在前景時即時更新手機電池狀態。
- 充電狀態及系統外觀變更時更新小工具。
- WorkManager 約每 15 分鐘執行背景更新。
- Android 可能依省電政策延後背景工作，更新時間不保證精準。
